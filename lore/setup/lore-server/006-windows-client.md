# Windows client の初回接続

[server の受入確認](005-acceptance.md) を完了してから、client を接続する。

[Windows CLI インストール手順](../001-windows-cli-setup.md) に従い、互換性を確認した client の配置、
certificate の信頼、Entra login と clone を確認する。ログインする利用者は先に
[bridge の利用者登録](../lore-auth-bridge/010-user-onboarding.md) で
identity を登録する。接続に失敗した場合は [TLS の確認と切り分け](../../operations/001-tls-troubleshooting.md) を参照する。

続けて [導入後の運用](007-post-deployment.md) を確認する。
