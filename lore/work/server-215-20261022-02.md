# 172.20.12.215: gRPC client IP forwarding の設定

2026-10-22 に、`172.20.12.215` の nginx gRPC proxy から `lore-auth-bridge` へ
client source IP を渡す設定を追加した。

## 目的

Service Account login は、account が所属する group の CIDR と client source IP を照合する。
bridge は nginx から loopback 経由で接続されるため、TCP peer address だけでは実際の
Jenkins runner IP を取得できない。

nginx が受信した client address を `x-lore-client-ip` gRPC metadata として渡す。
bridge は loopback の trusted proxy から受け取った metadata だけを CIDR 判定に利用する。

## 変更内容

対象 file:

```text
/etc/nginx/sites-available/lore-auth
```

`8081` server の二つの gRPC location に以下を追加した。

```nginx
grpc_set_header x-lore-client-ip $remote_addr;
```

適用後の gRPC upstream は次の形である。

```nginx
location ^~ /ucs.auth.RebacApi/ {
    allow 127.0.0.1;
    allow 172.20.12.215;
    grpc_set_header x-lore-client-ip $remote_addr;
    deny all;
    grpc_ssl_verify off;
    grpc_pass grpcs://127.0.0.1:18081;
}

location / {
    grpc_ssl_verify off;
    grpc_set_header x-lore-client-ip $remote_addr;
    grpc_pass grpcs://127.0.0.1:18081;
}
```

更新前の nginx configuration は次に backup した。

```text
/etc/nginx/sites-available/lore-auth.bak.20261022T054626Z-client-ip-forwarding
```
