# 172.20.12.215: Jenkins Service Account の作成と権限付与

2026-10-22 に、`172.20.12.215` の Lore auth bridge へ Jenkins 用 Service Account を
作成し、Jenkins runner の CIDR と `Watch` repository の writer 権限を group 経由で
付与した。

## Service Account

| 項目 | 値 |
| --- | --- |
| User ID | `f3012735-597e-4de9-835b-e4aa5bc50da3` |
| Client ID | `jenkins-user` |
| Display name | `Jenkins` |

作成時に発行された client secret は console、repository、作業記録には出力していない。
次の bootstrap file に `user-id<TAB>client-id<TAB>client-secret` の一行として保存している。

```text
/home/mgs/lore-auth-bootstrap/jenkins-user
```

file permission は `mgs:mgs 0600` である。Jenkins credential store への登録時だけ、215 上で
次の command を実行して三列目を取得する。

```bash
cut -f3 /home/mgs/lore-auth-bootstrap/jenkins-user
```

Jenkins credential store への登録と login 成功を確認したら bootstrap file を削除する。

```bash
rm -f /home/mgs/lore-auth-bootstrap/jenkins-user
```

## Group、CIDR、repository grant

| 項目 | 値 |
| --- | --- |
| Group | `jenkins-runners` |
| Group ID | `25e70703-ab83-48b6-8d06-9cd551c3957a` |
| Runner CIDR | `172.20.16.41/32` |
| Repository | `Watch` |
| Role | `writer` |

grant subject は `group:jenkins-runners` である。Service Account に direct grant を付与せず、
group membership を通じて network CIDR と repository role を継承させている。

作成時に実行した主な command:

```bash
/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  service-account add \
  --client-id jenkins-user \
  --name "Jenkins"

/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  group add jenkins-runners \
  --description "Jenkins runner service accounts"

/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  group member add jenkins-runners f3012735-597e-4de9-835b-e4aa5bc50da3

/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  group network-cidr add jenkins-runners 172.20.16.41/32

/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  grant add group:jenkins-runners Watch writer
```

認可判定は `allow` を確認済みである。

```bash
/opt/lore/bin/lore-authctl \
  --config /opt/lore/config/lore-auth.yaml \
  check f3012735-597e-4de9-835b-e4aa5bc50da3 Watch write
```

初期設定時は `172.20.11.161/32` を指定したが、GitHub Actions workflow の実測 source IP は
`172.20.16.41` だった。Service Account login が `service account network is not allowed`
で拒否されたため、初期 CIDR を削除し、`172.20.16.41/32` へ置き換えた。

## GitHub Actions 検証

Jenkins 実装とは別に、`gs-dev-platform-team/gspcd954` の self-hosted GitHub Actions
runner で検証した。

1. runner の Local Machine Trusted Root store に 215 certificate を import。
2. repository secret `LORE_JENKINS_USER_CLIENT_SECRET` に client secret を登録。
3. [`lore-service-account-215-test.yml`](https://github.com/gs-dev-platform-team/gspcd954/blob/main/.github/workflows/lore-service-account-215-test.yml)
   を実行。
4. login と `Watch` clone が成功:
   <https://github.com/gs-dev-platform-team/gspcd954/actions/runs/39734959838>

検証成功後、bootstrap secret file
`/home/mgs/lore-auth-bootstrap/jenkins-user` は削除済みである。
