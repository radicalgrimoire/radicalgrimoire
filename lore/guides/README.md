# Lore 利用・管理ガイド

Lore CLI を使う利用者と、`lore-authctl` を使う管理者向けの操作ガイド。
使用する binary の revision によりコマンドや引数が異なるため、実行前に確認する。
一般化した手順は実環境で通し検証していない。

## ガイド

1. [Lore CLI の基本操作](001-cli-usage.md) — Windows から login、clone、commit、push を行う。
2. [lore-authctl による利用者・権限管理](002-authctl.md) — 管理者が user、group、
   repository grant、Service Account などを管理する。
