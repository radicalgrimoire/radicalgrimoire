# 編集中のファイルを元に戻したい

主に編集中のファイルを元に戻したい場合は、主にRevertを使って元に戻します

# 編集中のチェンジリストを選択　→　Revert Files を押す

![revert-opened-files-01.png](https://raw.githubusercontent.com/radicalgrimoire/radicalgrimoire/refs/heads/main/images/perforce/user-guide/p4v/revert-opened-files/revert-opened-files-01.png)

戻したいファイルを選択して元に戻す
